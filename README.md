# JARVIS — 声で使えるマーケットアナリスト秘書

画面を開いておくと常に聞き取りを続け、「ジャービス」と呼びかけると、世界の市況・個別銘柄の分析を声で答え、詳しい数値は画面にレポートとして出します。

## 分析の考え方（正確さのために）
- 価格・騰落率・指標は、AIの記憶ではなく、相場データ（Yahoo Finance）をその場で取得し、サーバー側のプログラムで計算します。AIは計算済みの数値だけを使って解説します
- ニュース・決算・材料・経済指標・日銀/FRBの動き・信用倍率などは、Web検索で日付つきで裏取りします
- 返事には「何時時点のデータか」を添え、事実（データ）と見立て（解釈）を分けて話します
- 売買を断定的に勧めず、強気・弱気のシナリオと注目すべき価格水準を示します

## 話しかけ方の例
| 内容 | 例 |
|---|---|
| 世界の市況 | 「今日の相場どう？」「米国市場はどうだった？」「為替と金利は？」 |
| 個別銘柄の分析 | 「トヨタを分析して」「エヌビディアのテクニカルは？」「レーザーテックは押し目？」 |
| 財務・割安度 | 「トヨタのPERと配当利回りは？」「次の決算はいつ？」 |
| 比較 | 「NVIDIAとAMDとTSMCを3カ月で比べて」「日経平均とS&P500の年初来は？」 |
| 業種 | 「今週、日本で強い業種は？」「米国のセクター別の動きは？」 |
| 材料・ニュース | 「今日日経が下がった理由は？」「次のFOMCはいつ？」 |
| ウォッチリスト | 「NVIDIAとトヨタをウォッチリストに入れて」「ウォッチリストどう？」 |
| 価格アラート | 「ドル円が155円を超えたら教えて」「トヨタが2,500円を割ったら知らせて」 |
| 計算 | 「1万ドルを今のドル円で円にするといくら？」 |
| その他 | タイマー、リマインダー、メモ、記憶、天気、予定（カレンダー接続時） |

### 個別銘柄の分析で出すもの（analyze_stock）
騰落率（1週〜1年・年初来）、移動平均（5・25・75・200日）の値・傾き・乖離率、パーフェクトオーダー判定、RSI(14)、MACD（クロスの検出）、ボリンジャーバンド(20日±2σ)、ATR、ボラティリティ、1年の最大下落率、52週・60日・20日の高値安値、出来高と売買代金、日経平均/S&P500との相関・ベータ・超過リターン。

日本株は、押し目買い手法のチャート条件（5日線より上／パーフェクトオーダー／5・25・75日線が上向き／出来高100万株以上）を ○× で判定し、5日線・25日線までの距離も出します。信用倍率などの需給データは相場データに含まれないため、Web検索で補います。

### 財務（get_fundamentals）
時価総額、PER（実績・予想）、PBR、EV/EBITDA、EPS、配当利回り・配当性向・権利落ち日、売上・利益成長率、利益率、ROE、負債、フリーキャッシュフロー、アナリスト目標株価と評価、次回決算日など。

## 画面の見かた
- 上部の帯：主要指標（日経平均・S&P500・NASDAQ・SOX・ドル円・米10年金利・金・WTI・ビットコイン）とウォッチリストが流れます（約1分ごとに更新）
- 分析を頼むと、中央に「REPORT」（詳細レポート）が開きます。×で閉じ、右上の「REPORT」で再表示できます
- 待機中は細い一本線、話している間は横線が波打ち、考えている間はもやもやが動きます
- 右上の「PANELS」で、マイク音量・応答時間・会話ログ・メモなどのパネルを表示します
- 話している途中にタップすると、読み上げを止めてそのまま話せます

## 使い方
- 最初に画面をタップして起動（マイクの許可が必要です）
- 「ジャービス」と呼びかけて、そのまま用件を話す（呼びかけだけでも、ピッと鳴って続きを待ちます）
- 返事のあと約8秒は、呼びかけなしで続けて話せます（「もっと詳しく」「じゃあAMDは？」など）
- 呼び名・読み上げ速度・上部の帯の銘柄は、`index.html` の先頭近くの設定（`WAKE_WORDS` / `SPEECH_RATE` / `TICKER_BASE`）で変えられます

## ファイル
- `index.html` … 画面、常時聞き取り、読み上げ、ティッカー、レポート表示、ウォッチリスト・アラートの保存
- `api/voice.js` … 会話の中心（AIへの指示、道具の実行）。キーはここだけで使う
- `api/_market.js` … 相場データの取得と、指標・財務・比較・業種の計算
- `vercel.json` … 処理の制限時間を60秒にする設定
- `manifest.json` … ホーム画面に追加するための設定

## 公開・更新の手順（スマホだけでOK）
1. GitHubのリポジトリに、`Add file > Upload files` で `index.html`、`manifest.json`、`vercel.json`、`api`フォルダ（`voice.js` と `_market.js` の2つ）をアップロード（同じ名前は上書き）
2. 初めての場合は、Vercelで `Add New > Project` からそのリポジトリをImport（設定はそのままでDeploy）。2回目以降は自動で反映されます
3. Vercelの `Settings > Environment Variables` を設定して、Redeploy
4. 発行されたURLをスマホのブラウザで開く

### 環境変数
| 名前 | 必須 | 内容 |
|---|---|---|
| `GROQ_API_KEY` | 必須 | GroqのAPIキー |
| `APP_PASSCODE` | 強く推奨 | 自分だけが使うための合言葉 |
| `USER_NAME` | 任意 | 呼んでほしい名前 |
| `USER_PROFILE` | 任意 | 分析に反映してほしい自分の前提（例: 投資スタイル、主な保有資産の傾向、重視する指標）。GitHubではなくここにだけ書く |
| `GROQ_REASONING_EFFORT` | 任意 | AIの考える深さ low / medium / high（既定 medium。high は深いが返事が遅くなる） |
| `GROQ_CHAT_MODEL` | 任意 | 会話のモデル（既定: openai/gpt-oss-120b） |
| `GROQ_FALLBACK_MODEL` | 任意 | 予備のモデル（既定: llama-3.3-70b-versatile） |
| `GROQ_SEARCH_MODEL` | 任意 | Web検索に使うモデル（既定: groq/compound-mini。より詳しく調べたいときは groq/compound） |
| `GCAL_ICS_URL` | 任意 | Googleカレンダーの「iCal形式の非公開URL」 |
| `DEFAULT_LOCATION` | 任意 | 天気の既定の場所（ローマ字。既定は Fukui） |
| `GROQ_STT_MODEL` | 任意 | 文字起こしのモデル（既定: whisper-large-v3-turbo） |

## データについての注意
- 相場データは Yahoo Finance の公開データを使っています（キー不要）。公式の契約データではないため、仕様変更や混雑で取れないことがあります。その場合は Stooq の日足終値で代わりに答え、そう伝えます
- 日本株は約20分遅れのことがあります。米国株・為替・先物も、取引所によっては遅延があります
- 日本株の財務項目は、欠けていたり更新が遅かったりすることがあります。会社予想や最新の決算内容は、Web検索で確認するように指示しています
- 信用倍率・貸借倍率・回転日数、値上がり率ランキングなどは相場データに含まれないため、Web検索で補います（取得元のサイト次第で精度が変わります）
- 分析は判断材料の提供であり、投資の最終判断はご自身で行ってください

## 動作上の注意
- Groqの無料枠では、1分あたりに使える文字量の上限が小さく、分析が続くとエラー（429）になることがあります。そのときは予備モデルに自動で切り替えますが、頻繁に起きる場合はGroqの有料プラン（Developer）をおすすめします
- ブラウザの仕組み上、画面を点けてこのページを開いている間だけ聞き取ります。価格アラート・タイマーもページを開いている間だけ動きます
- Androidの Chrome が一番安定します。iPhoneのSafariは常時聞き取りが途切れやすく、タップ操作が必要になることがあります
- APIキー・合言葉・カレンダーURLは、チャットやGitHubには貼らず、Vercelの環境変数にだけ入れてください
